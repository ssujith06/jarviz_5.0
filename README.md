     An AI-powered voice and text assistant built with LiveKit Agents and Google Gemini Realtime API.
     This project simulates a personal assistant (inspired by Jarvis) that can listen, understand, and respond in real-time using both speech and text.

**Features**
     Voice Input & Output: Talk to the assistant naturally using your microphone.
    
     Text Input: Chat with the assistant directly in the terminal.
    
     Noise Cancellation: Integrated BVC noise cancellation for clearer communication.
    
     Realtime AI Responses: Powered by Gemini 2.0 Flash Realtime for quick, natural replies.
    
     Customizable Personality: The assistant can follow custom instructions (e.g., behave like Jarvis, a helpful assistant, or a domain expert).
    
**Tech Stack**
    Python 3.12+
    LiveKit Agents SDK
    Google Gemini Realtime API
    dotenv for environment variable management

**Setup & Installation**

      1.Clone the repository
      
      git clone https://github.com/your-username/jarvis-ai-assistant.git
      cd jarvis-ai-assistant
      
      2.Install dependencies
      
      pip install -r requirements.txt
      
      3.Set up environment variables
      Create a .env file in the root folder and add your API keys:
      
      GOOGLE_API_KEY=your_google_api_key_here
      LIVEKIT_API_KEY=your_livekit_api_key_here
      LIVEKIT_API_SECRET=your_livekit_secret_here
      
      5.Run the assistant
      
      python agents.py
